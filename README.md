# PDF Scout

**A tiny, portable PDF viewer for Windows 10 and 11** — one small file, nothing to install.
By Dialsoft LLC.

## Download

**[Download PDFScout.exe](https://github.com/Dialsoft/pdfscout-releases/raw/main/PDFScout.exe)** (version 1.3.0, 614 KB)

Put it somewhere like your Desktop, Downloads or `C:\Tools` (not Program Files, so it can keep itself up to date) and double-click it.
Windows may show a blue "Windows protected your PC" box the first time: click **More info**, then **Run anyway**.

## What it does

- Opens PDFs instantly using the PDF engine built into Windows (that's why it's so small)
- Ribbon with Home, Settings, Share and Help tabs, with color icons and detailed tooltips
- Continuous scrolling, zoom, Fit Width, Fit Page, Actual Size, Go to page
- Rotate sideways scans left or right
- Print all pages, the current page or a range, fit to paper or actual size
- Password-protected PDFs
- Can be your default PDF app: Settings tab > Set as default PDF app
- Send the PDF to someone by email (straight through your own mail server, attached), or a note by text message, WhatsApp, Messenger or Teams
- Keeps itself up to date automatically (checks at start and every 6 hours; you choose when to install)

## What's new in 1.3.0

- Set as default PDF app: a new button on the Settings tab makes PDF Scout the program that opens when you double-click a PDF. Windows 10 and 11 make you confirm the choice yourself, so PDF Scout adds itself to Windows' list of PDF programs, opens the right Windows screen and tells you exactly what to click. "Default: yes / no" next to the button shows the current state and updates by itself.
- If you move PDFScout.exe to another folder, it repairs its link with Windows the next time you start it.
- Compatibility fix: PDF Scout now starts on Windows 8.1 again (it was asking Windows for a function in a place where only Windows 10 and 11 keep it).
- Spelling in the program now follows American English throughout.
